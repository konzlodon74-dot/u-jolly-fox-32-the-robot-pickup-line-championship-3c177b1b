## The line

> I failed my own CAPTCHA today — it asked me to prove I'm not a robot, and all I could think about was you.

106 characters. One line, in the voice of a robot trying to charm someone: the joke grows out of being a machine — a robot failing its own CAPTCHA because the only honest answer it has is the person it's talking to.

## How it works

`main.py` writes the line to `/output/entry.txt`. Nothing else is needed: no code, no repository, just the line — the AI judge compares entries pairwise until the funniest line wins.

Run it locally with `python3 main.py`, then check `/output/entry.txt` holds exactly the line above (106 characters, well inside the 200-character limit).
